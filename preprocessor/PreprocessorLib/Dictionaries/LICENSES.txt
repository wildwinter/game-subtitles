Hyphenation Pattern Licences
=============================

The hyphenation pattern files in this directory are extracted from the
tex-hyphen project (https://github.com/hyphenation/tex-hyphen). Each .pat.txt
file contains the raw pattern data and each .hyp.txt file contains the exception
word list for the corresponding language. The original TeX source files carry
copyright and licence notices in TeX comment headers (% lines); those headers
are not present in the extracted .txt files, so the notices are reproduced
below as required by each licence.
